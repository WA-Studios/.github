## About WA Studios

**WA Studios** creates modern and polished resources for **FiveM servers**.

Our goal is simple: build resources that are easy to install, easy to configure and enjoyable to use — without sacrificing performance or visual quality.

Every resource is designed around three core principles:

⚡ **Performance** — Optimized and lightweight resources  
🎨 **Design** — Modern and consistent user interfaces  
🛠️ **Developer Experience** — Clean configuration, integrations, exports and events
